# Independent funding-rank feature reconstruction

`audit/verify_funding_rank_features.py` is a separate offline auditor. It imports no production signal builder, strategy, runner or Engine. Its only funding arithmetic dependency is the already independent scalar `funding_sequence`/`reference_at` implementation from `audit/verify_cross_venue_features.py`; both auditor sources are hashed before and after certification.

Before any numerical certification it requires full source and input Git commit anchors. The exact frozen lock, input verification and preregistration bytes must match the input anchor. The lock must contain the exact reviewed transitive source set and the exact normalized/catalog/raw archive/funding-page inputs reconstructed from manifests. Each executed source must match the source commit, live source and archived source. Runtime versions, candidate27/five phases and the explicit pre-feature/pre-trial preregistration claims are checked. A self-consistent reseal cannot replace the Git anchor.

It checks all525,598 availability minutes and24 columns, exact source-year minute grids, native1000PEPE identity, positive finite prior closes and the two-minute price lag. It reconstructs every daily00:05 predictor from only settlements whose assumed or supplied receipt plus processing minute is strictly earlier than the decision. Chronological predecessors are rebuilt within the known subset; no pre-year predecessor is allowed. Recognized elapsed durations, seven-day overlap weighting,151.2-hour coverage, mixed/invalid cadence overlap, stale settlement age and exact validity/yield semantics are independently compared. Other minutes must be invalid with missing yields. Sunday policy selection is a separate intent audit, not a feature claim.

Thirteen synthetic adversaries cover known constant-rate arithmetic, delayed older receipts, same-clock strict availability, unpublished past records, incorrect native boundary records, forbidden pre-year warmup, changed prices/yields/flags/columns/clocks and internally resealed unreviewed assumptions. Actual historical reconstruction has not yet been dispatched or run. The eventual fresh certificate records exact common feature/lock/receipt hashes, Git anchors, source stability and per-stream comparison counts. No collector rerun, fitting or economic model execution is involved.

Limitations remain explicit: source settlement history does not prove historical receipt time or an announced earning-period schedule; recognized elapsed durations are a conservative realized proxy; systematically missing regular events can mimic a cadence. Exact predictor reproduction establishes causal arithmetic under the frozen assumptions, not forecast accuracy, profitability or untouched validation.
