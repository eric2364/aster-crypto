Before any numerical certification it requires full source and input Git commit anchors. The exact frozen lock, input verification and preregistration bytes must match the input anchor. Chronological predecessors are rebuilt within the known subset; no pre-year predecessor is allowed. Recognized elapsed durations, seven-day overlap weighting,151.2-hour coverage, mixed/invalid cadence overlap, stale settlement age and exact validity/yield semantics are independently compared. Other minutes must be invalid with missing yields. Sunday policy selection is a separate intent audit, not a feature claim.

Thirteen synthetic adversaries cover known constant-rate arithmetic, delayed older receipts, same-clock strict availability, unpublished past records, incorrect native boundary records, forbidden pre-year warmup, changed prices/yields/flags/columns/clocks and internally resealed unreviewed assumptions. No collector rerun, fitting or economic model execution is involved.

Limitations remain explicit: source settlement history does not prove historical receipt time or an announced earning-period schedule; recognized elapsed durations are a conservative realized proxy; systematically missing regular events can mimic a cadence. Exact predictor reproduction establishes causal arithmetic under the frozen assumptions, not forecast accuracy, profitability or untouched validation.
