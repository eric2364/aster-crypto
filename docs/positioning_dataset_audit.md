# Independent full positioning dataset audit

This is a data-only source and normalization audit. `audit/verify_positioning_dataset.py` imports neither the collector nor the source probe. It uses a separate scalar CSV parser and reconstructs observations from the retained official-shaped ZIP contents, preserving native quantities, raw textual labels, source-day identity and original row indices.

The declared window is 2025-10-05 through 2026-10-05 UTC, exclusive at the end. The source anchor is `241a6502a939a4bfe27dea938bdb5ef151808f46`; its exact collector bytes must equal both the current source and the executed-source archive. Each raw retrieval receipt must pin that same acquisition implementation. The normalized dataset consists of eight native instruments including **1000PEPEUSDT**, with 105,120 observations per instrument on the assumed five-minute grid.

Verification checks the exact root/native/day/file namespaces before reading sealed file maps; rejects symlinks and traversal maps; validates 2,920 ZIP filenames/members, CHECKSUM filenames/hashes, native CSV schema, finite positive numeric values, raw request URLs, explicit UTC retrieval receipts, source hashes and parser diagnostics. It independently normalizes chronological order and compares every normalized field exactly against the parquet, including source strings and original source row indices. It reconstructs the complete manifests and collection metadata, and checks all 18 normalized/source seals and 2,920 raw receipt seals. It rehashes raw and normalized evidence, collector source/runtime and its own source before certifying completion. No missing observations are filled, labels shifted or duplicate records selected.

A daily end-labelled set can be parsed as source evidence, but it is not silently shifted into the year. Annual duplicate/missing/outside-year clocks fail. The exact full-grid acceptance concerns physical labels, not verified contractual interval semantics. Today's official archives and CHECKSUMs do not prove that these same files existed unchanged at the original observation time.

Synthetic validation: **32 tests passed in 1.27 seconds**. Cases independently construct known reversed-order 288-row archives and verify retained native identities and values. They reject resealed normalized quantity, source-string, row-index, native-ID and timestamp mutations; source/UTC/checksum/diagnostic receipt tampering; wrong schema/grid/numeric/source records; extra namespaces, traversal and symlinks; fabricated availability; and raw/source/runtime mutation during the audit. No real economic feature or outcome is inspected.

The tested independent auditor SHA256 is `12749f9fe814909e8cd356404c0729eb18705488bb072321a93ae7dfd3e76df2`. It was recorded before the actual offline run; the certificate requires those source bytes to remain unchanged until completion. The actual certificate is written exclusively to a fresh `audit/positioning_dataset_evidence.json` after successful full reconstruction. The collector is never rerun by this auditor.

## Limits

Offset-free source labels are explicitly interpreted as UTC and the 300-second grid is an assumption checked against physical observations. The audit does not prove original publication/delivery times, absence of archive revisions, historical contract/unit semantics, or an executable predictor. The source reports quantity OI and value OI separately; a change in value is not automatically a quantity change. This does not establish profitable positioning strategies, untouched validation, or any additional successful candidate. Any future signal requires a separately frozen availability policy and causal tests.
