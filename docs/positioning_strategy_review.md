## Additional adversarial finding: signoff temporarily withdrawn

A further parent-raised case revealed a material gap after the initial review: the public event scan checked only IDs still live after the whole event batch. An unowned order accepted and filled before the next callback disappeared from that set. If it added another long unit to the already selected holding, the old inventory check also missed it. The independent reproduction changed the selected quantity100→101 and recorded accepted/filled foreign events; the strategy stayed `HOLDING` with no abort. Thus the earlier prospective source signoff is withdrawn pending repair and rerun, before any historical feature or outcome use.

Required repairs are to latch newly seen unowned accepted events regardless of later terminal status, cancel only the foreign IDs still live, and enforce the actual full holding vector against its immutable completed targets. A flat unowned accepted/cancelled episode must still be a failure with the fixed cooldown; recognized own accepted/filled events must not false-trigger. Independent regressions were added for all these cases. This is an execution-integrity finding, not a change to the economic hypothesis.
